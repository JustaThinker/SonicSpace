# SonicSpace Release Information

This document tracks version releases, highlights, and milestone updates for **SonicSpace**.

---

## SonicSpace 1.5.0 (Upcoming)

[Download on GitHub Releases](https://github.com/JustaThinker/SonicSpace/releases/latest)

### Highlights & New Features
* **Elevated Dynamic Navigation Bar**:
  * New Dynamic Navbar option with spacious 76–88 dp dimensions and scroll-to-hide ergonomics on continuous feeds.
  * Individual floating icon pill containers with 2–6 dp tonal and shadow elevation.
  * Navigation bar visibility strictly scoped to primary root tabs (Home, Search, Library).
* **Harmonic Dynamic Theming (SpatialFlow Engine)**:
  * Fine-tuned HSL harmonic color scheme that extracts gentle, elegant background seeds from album artwork.
  * Non-harsh saturation clamping (0.16–0.38) preventing piercing neon contrast in dark and light modes.
  * True AMOLED Pure Black mode support (`#000000` surface containers) integrated seamlessly.
* **Haptic Feedback Service**:
  * Custom tactile vibration feedback engine with user-adjustable strength (0–100%) and responsive gestures across all controls and navigation tabs.
* **Modular Architecture**:
  * Clean reorganization of 16 submodules into a clean `modules/` structure (`core`, `playback`, `lyrics`, `canvas`, `innertube`).
* **Onboarding Refresh**:
  * Rebuilt setup flow with live interactive navigation style previews and high-contrast light mode design.

## SonicSpace 1.4.0

### Highlights & New Features
* **Ad-Free Music Streaming** — Stream high-quality audio ad-free from YouTube Music.
* **Redesigned Search & Explore** — BitChord-inspired responsive grid with duotone category cards and dynamic background artwork loading.
* **Smart Home Feed** — Prioritized Daily Discover, Picked for You, Forgotten Favorites, and Community Playlists in a clean, stable layout.
* **Liquid Glass Visual Effects** — Frosted glass translucent top app bars and floating navigation toolbars.
* **Multi-Source Synced Lyrics & AI Translation** — Real-time synced lyrics with word-by-word highlights from LRCLIB, KuGou, BetterLyrics, YouLy, and Paxsenix, plus on-the-fly AI translation.
* **Spotify Fast Sync** — One-tap import and fast synchronization of your Spotify playlists and library.
* **Sonic Find** — Integrated ambient music recognition powered by microphone listening.
* **Listen Together** — Synced real-time listening rooms to stream music with friends.
* **Offline Playback & Downloads** — Download songs, albums, and playlists for offline listening.
* **Enhanced Typography & Track Rows** — Refined track row styling, unboxed list presentation, and clear hierarchy between track title and artist.
* **Discord Rich Presence & Google Cast** — Share what you're listening to on Discord or cast to Chromecast devices.
